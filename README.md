# C Day 79 - Sum of Positive Numbers

This C program calculates the sum of positive numbers entered by the user.

## Example

Input numbers:
```text
10, -5, 20, 0, -3
```

Output:
```text
Sum of positive numbers = 30
```

## Concepts Used

- `for` loop
- `if` statement
- Variables
- `scanf()` and `printf()`
- Addition operator

## How It Works

The program accepts multiple numbers from the user. It checks whether each number is greater than zero. Only positive numbers are added to the total sum.

## What I Learned

I learned how to use a loop and an `if` statement to calculate the sum of positive numbers in C.
